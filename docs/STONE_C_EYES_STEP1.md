# C 成男眼球拆分 · 第一步：切分路径候选

仅定位路径，本步不切网格、不替换眼球、不改变在线工具。

- 路径沿上下眼睑内缘闭合，在内外眼角接合；不是沿眉毛或外侧骨性眼眶切割。
- 左右各 96 个表面采样点，落在原 C 资源的实际三角面上；每点记录源三角面、顶点索引和重心坐标。
- 路径是平滑的表面引导线，并非原有连续边环。原眼区三角面不规则，下一步需对穿过的三角面进行局部切分，不能直接删除大块面片造成眼角缺口。
- 路径内侧是待分离的旧眼部表面；保留眉毛、眼角锚点和外侧眼眶。切口之后需要向眼眶内侧建立眼睑厚度与支撑环，不能将单层面片作为完整眼皮。
- 本步未确定眼球半径、中心深度或最终瞳孔尺寸，避免仅凭正视贴图估算。下一步装配时以侧面遮挡和眼皮覆盖为约束，成男瞳孔需小于少年，虹膜与瞳孔分别控制；闭眼需上下眼皮汇合，不能用眼球缩放代替。

数据：`docs/stone-c-eye-cut-guide.json`，原资源校验用 SHA256 包含在数据中。所有坐标为原资源静止空间、单位米，尚未经过编辑器参数形变和骨骼变换。

重建：`python scripts/plan-stone-c-eyes.py`（numpy / scipy）。检查：192 点重心坐标合法、重建残差小于 1e-9 m；闭合投影无自交；源模型文件及所有运行模块不变。CPU 正交图用于路径审阅，不表示已完成浏览器 WebGL 或眼球装配验收。

后续顺序：局部切分并分离旧眼部表面 → 安装成男眼球 → 建立上下眼皮及支撑环 → 闭眼/眨眼形变 → 参数、动作和存档回归。
