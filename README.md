# CharaBuilder · 角色工坊

基于 Three.js 的轻量浏览器捏人工具，中文界面，无构建步骤、无需安装 npm 依赖。

## 启动（Windows / PowerShell）

安装 Python 3 后，在项目目录执行：

```powershell
py -m http.server 8000 --directory dist
```

浏览器打开 http://localhost:8000 。macOS / Linux 可使用 `python3` 替代 `py`。请通过 HTTP 访问，不要双击 HTML 文件（浏览器 ES Modules 需要 HTTP）。需要支持 WebGL 的现代浏览器。

## 功能

- 男女日漫身体，身高、头部、肩宽、胸腰臀、腿长和粗细等参数。
- 五官、下巴、额头、鼻梁、嘴部位置及 6 种表情。
- 参考 CC0 成熟发型的分区编辑：前发、后发、侧发与马尾独立组合，保留原作者的发束拓扑、UV、层次、卷曲和纹理。提供经典波波、柔顺长发、层次短发、双马尾、侧卷马尾组合；长度和蓬松度由 JS 参数控制。
- 男女衬衫与长裤：衣长、袖长、衬衫宽松度和裤腿宽度；另有女性运动内衣配内裤、男性贴身平角内裤版本。穿鞋 / 光脚独立选择，颜色和身体参数继续有效。
- 旋转、缩放、全身 / 面部视角，多角色本机存档，JSON 参数导入 / 导出。

旧整套发型存档迁移为分区参数，旧服装统一转为衬衫配裤子，原有身材、五官和颜色保留。存档使用浏览器 localStorage；请导出 JSON 备份。JSON 是角色参数档案，不是 GLB、骨骼或贴图。

## 项目结构

- `dist/app.js`：中文界面、参数、存档和异步更新。
- `dist/parameters.js`：人体和五官的共享空间变形。
- `dist/hair.js`：按完整发束拆解 CC0 成熟发型、选择组合、头部适配和有界参数变形。
- `dist/underwear.js`：在成人基础身体表面裁剪贴身内衣，保留约 2 mm 间隙。
- `dist/wardrobe.js`：衬衫与长裤的 JS 剪裁和版型参数，以及程序生成的纽扣位置。
- `dist/anime.js`：基础网格加载、组合、变形、法线和 Three.js 材质。
- `dist/assets/anime/`：CC0 基础网格和贴图；旧发型、服装资源作为历史来源保留。
- `scripts/prepare-vroid.py`、`scripts/fit-vroid-presets.py`：基础资源的可复现转换流程。
- `dist/vendor/`：本地 Three.js / OrbitControls，无 CDN 运行依赖。

人体保留 CC0 VRoid beta 模型的拓扑、UV 和初始顶点，JS 计算最终形状。发型基于旧版 CC0 HairSample_Female、Sendagaya Shibu、Sendagaya Shino、Sakurada Fumiriya、Victoria Rubin 的作者网格。按网格连通的完整发束分区，保留原有拓扑、渐细轮廓、UV 与纹理，不再用重复数学发束凑轮廓；头皮帽沿用经过头部表面拟合的源网格。经典组合优先保持同一作者发型的设计，各区仍可独立搭配。马尾来源为原版双马尾和侧卷马尾，当前不含编织辫。新增几何不依赖受限的 VRoidPreset A–Z，不包含原始 VRM 文件。衬衫和长裤沿用第一种方案，保留现有衣物的拓扑，由 JS 调整衣长、袖长和宽松度；女裤由 CC0 男裤基础网格适配。鞋履沿用原有基础模型。

人体、衣服和头发应用同一身体变形；五官与眉毛应用同一脸部变形。衣物不依赖原来的领结、领带、背心或花纹贴图，当前为纯色衬衫与裤子。衬衫长裤模式裁去衣物覆盖区的隐藏身体三角形；袖长改变时调整遮挡区域。内衣模式恢复完整身体与手脚，服装由身体表面裁剪生成，并随身体参数共同变形。光脚模式移除鞋网格，依据可见脚底落地；包围盒只计入可见三角形。此工具支持骨骼预览动作，尚无 GLB / VRM 导出。极端参数组合仍需实际画面检查。

用 HTTP 启动后即可使用；可直接部署 `dist` 或使用根目录入口部署 GitHub Pages。浏览器需支持 WebGL、ES Modules 和 DecompressionStream。资源来源与许可见 THIRD_PARTY.md。

## 验证

无需安装依赖，Node.js 24：

```sh
node tests/parameters.mjs
node tests/archive.mjs
node tests/modular.mjs
```

覆盖全部男女分区发型组合、极端参数、关闭所有发区、内衣 / 外衣与穿鞋 / 光脚切换、完整身体恢复、脚底落地、网格数据和存档迁移。几何数据检查不能替代 WebGL 画面验收。

下面保留原始 CC0 资源转换说明；新版仅使用其中的身体、脸、衬衫和裤子基础结构。

### 扩展预设转换

旧版 CC0 源文件位于 `madjin/vrm-samples/vroid/beta`。在上述基础模型目录下创建 `donors`，将 `Sendagaya_Shibu.vrm`、`Sendagaya_Shino.vrm`、`Sakurada_Fumiriya.vrm`、`Victoria_Rubin.vrm` 分别命名为 `bob.vrm`、`long.vrm`、`uniform.vrm`、`classic.vrm`。然后运行：

```sh
python scripts/prepare-vroid.py 该目录/donors bob long uniform classic
python scripts/fit-vroid-presets.py
```

转换采用共享基础骨架，按皮肤 UV 对应保留当前头部，发型与服装可以独立选择。遮挡皮肤和衣物来自同一套源网格；头发保留嵌入头皮的根部，末端按各套装的表面修正间隙。服装仍以整套切换，不支持任意混搭上装与下装。


### v10 骨骼动作

角色现在使用 Three.js `SkinnedMesh` 和共享 `Skeleton`。CC0 beta HairSample 的原始身体/面部四权重蒙皮保存在压缩的 `female-rig.b64` / `male-rig.b64` 中；骨架先应用当前身材参数，再计算绑定矩阵。服装、内衣与纽扣通过身体表面的空间邻域转移蒙皮权重；头发初版整体绑定头骨。

预览支持自然待机、查看身体（低头、抬手、左右查看）、静止姿势和暂停/继续。正面视角按钮同时恢复静止姿势，关闭自动旋转。动作使用 JS 时间函数驱动骨骼，未引入额外 GLB/VRM。当前没有头发物理、脚部 IK 或布料模拟；大幅动作和极端服装参数仍需进一步调整权重。

验证：`node tests/rig.mjs` 检查男女、衬衫长裤/内衣、默认/极端身材的权重归一化、绑定姿势一致性、骨骼动作、有限坐标与恢复姿势。`scripts/prepare-rig.py SOURCE_DIR` 可从原 CC0 HairSample 源文件重建蒙皮数据。

### v11 肤色一致性

脸部贴图现在先在线性颜色空间中去除原始肉色底色，再叠加所选肤色。局部鼻唇和耳部细节保留并减弱，眼睛、眉毛、睫毛与口腔材质独立保留。身体和脸使用相同肤色，不再重复相乘基础肉色。

### v12 内衣与 HSL 调色

女性上装改为无肩带抹胸，内衣外侧间距增加至 4.5 mm。裁切顶点插值并归一化原始身体蒙皮权重，减少动作时因权重不同造成的穿模。面容分类新增瞳孔颜色；虹膜贴图转换为亮度细节，保留深色瞳孔和独立高光。

肤色、发色、瞳孔颜色、上装和下装均保留快捷色，同时提供 HSL 色板、H/S/L 滑块及 HEX 输入。颜色直接更新材质，保持当前动作/暂停姿势。自定义颜色和瞳孔颜色随角色 JSON 保存，旧档案自动补充默认瞳孔颜色。

验证：`tests/colors.mjs` 检查 4096 组 RGB/HSL 往返；`tests/appearance.mjs` 检查实时改色、无肩带网格与姿势保留；`tests/archive.mjs` 检查五个颜色字段；`tests/rig.mjs` 检查服装蒙皮与身材极值。

### 分区发色

所有 `_HAIR` 材质现在从贴图中仅取亮度细节，保留透明边缘；按该材质实际使用的 UV 岛中值校准明暗，避免不同 CC0 来源的前/后/侧发把底色和底亮度乘到所选发色上。HSL 实时调色保持有效。


## 发型与服装参考要求

用户指定：新增发型、服装以他人已经建好的 3D 模型为基础，优先使用许可允许角色生成器复用的素材。保留原网格轮廓、分区和 UV，拆解并转换为 JS 可调整的几何数据；照片仅核对效果，不得以照片自创几何代替原模型。没有合适模型的款式留缺，不冒名替代。来源与转换细节见 [发型模型来源](HAIR_REFERENCES.md)。

v15 撤下 v13–v14 自造的圆寸、军式、平头、短碎四款，接入 Micket 的 CC0 侧分短发、上梳短发原网格。男性隐藏双马尾、侧卷马尾、波波和长发选项；女性隐藏本轮男性短发选项。分区选项、随机生成、性别切换和旧存档载入使用同一筛选规则。

验证：`node tests/hair-shorts.mjs` 检查 20 组原模型分区组合、原始面数、接缝连续性、参数极值和头骨动作；`node tests/archive.mjs` 检查男女合法选项往返、隐藏选项迁移及旧存档；骨骼与实时改色检查继续通过。

## 成熟面部来源调研

面部来源、许可及历次接入方式见 [FACE_REFERENCES.md](FACE_REFERENCES.md)。v18 新增独立 JS 面部模块 `dist/face.js`，两款命名为「绫 · 成女脸」「隼 · 熟男脸」。它们沿用已有日漫网格和组件，下载头模只提供颌部尺寸参考；不再加载整颗参考头部及其颈部。脸型和五官按实际区域直接变形，发型随编辑后的头部表面避让。新脸当前仅支持自然表情。

## v19 自由捏脸编辑

面部提供 24 个几何参数，范围 −50～150，按部位分成可折叠卡片。支持鼠标/触屏二维拖拽、脸部点位拖拽、数值输入、标签数值横向拖动、Shift 微调、部位重置和撤销/重做。新增参数实际修改 JS 网格，原版日漫和参考日漫均有效。交互来源与操作说明见 [EDITOR_REFERENCES.md](EDITOR_REFERENCES.md)。

验证：`node tests/editor.mjs`、`node tests/faces.mjs`、`node tests/archive.mjs`、`node tests/parameters.mjs`、`node tests/appearance.mjs`、`node tests/rig.mjs`。

## v21 体型部位编辑与瞳孔保护

基础分类提供 31 个几何参数，范围 −50～150。新增 21 个细分项，按整体比例、肩背、胸部、腰腹、臀胯、手臂与手掌、腿部、脚掌分成八组可折叠卡片；肤色单独保留 HSL 卡片。每组支持二维拖拽、身体点位拖拽、数字输入、Shift 微调、撤销/重做与独立重置。点位编辑恢复正面静止姿势，关闭后可旋转检查。

`dist/body.js` 在已有 CC0 人体拓扑和骨骼点位上做连续区域变形；身体、衬衫、裤子、内衣、鞋履和绑定骨骼共享这一坐标场。调整手臂/手掌不影响腿，腿部粗细避开手掌；改变躯干长度时头部和手臂一同跟随。仍为已有模型的 JS 参数化编辑，无新增下载模型或 GLB。

虹膜/瞳孔及高光现在使用独立区域，仅随眼部中心移动。眼睛的大小、宽度、高度、角度以及邻近脸型参数不再拉伸它们，保留原作者的尺寸和长宽比例；调整整个头部大小时统一等比缩放。眼白和眼睑继续按眼形参数变形。

验证：`tests/body.mjs` 覆盖男女 31 个参数的可见顶点位移、八处身体点位、衣物/裸足/身材自由边界的落地与蒙皮动作；`tests/faces.mjs` 增加两种面部来源中虹膜和高光的刚性平移检查；交互、数值存档、实时颜色与骨骼检查继续通过。

## v23 作者动作预设

新增 Quaternius Universal Animation Library Standard（CC0）中的六个现成动作：放松站姿、交谈手势、自然步行、挺拔步行、原地慢跑、舞蹈展示。保留原有轻微呼吸、查看身体和静止编辑姿势。选择器支持暂停与 0.5× / 1× / 1.5× 播放。

动作曲线来自作者的 glTF 轨道，经 `scripts/prepare-animations.py` 提取为 JS 数据；不加载 donor 模型、GLB 或替换身体。`dist/motion.js` 在现有 Three.js 骨骼上按世界旋转差重定向，补偿原身体已烘焙的放松手臂姿态，并保持用户调整后的关节长度。动作切换使用 0.22 秒插值；预览去除水平根位移，保留髋部上下起伏，对可见鞋底采样做高度修正。这是预览落地处理，尚不是带水平锁脚的完整 IK；极端身材、大幅动作仍需视觉检查衣物和关节形变。

来源、方法与可复现记录见 [ANIMATION_REFERENCES.md](ANIMATION_REFERENCES.md)。验证：`node tests/motion.mjs`，覆盖男女、内衣/衬衫裤装、普通/极端比例共 48 组动作配置；检查保留源曲线、有限蒙皮顶点、单位四元数、采样鞋底落地和恢复原静止姿势。

## v25 裤子动作明暗修复

裤子在 UV / 拼接边界的同位置顶点共享面积加权法线，消除弯腿时的法线断层。动作播放时根据蒙皮后的实际表面重新计算平滑法线，并逆变换回 GPU 蒙皮法线所需的空间，修正弯膝时单纯混合骨骼法线产生的错误明暗。恢复同一条 CC0 Sakurada Fumiriya beta 裤子的原作者蒙皮权重，通过骨骼名称映射到男女现有骨架；不再给裤子复制最近身体顶点的权重。原拓扑、UV、JS 宽度与体型参数保留。提取脚本为 `scripts/prepare-pants-skin.py`，只保存权重数据，没有新增运行时 VRM/GLB。

`node tests/pants.mjs` 验证男女三种裤宽下，223 组拼接点的单位法线、原作者权重与弯腿动作中的位置连续性、GPU 法线和实际变形表面的方向一致性；`tests/motion.mjs` 的 48 组动作配置与 `tests/rig.mjs` 的八组绑定检查继续通过。

## v26 作者手型与指节动作

保留底模已有的每指三节骨骼并接入 Quaternius 原作者的全部 30 节手指轨道。每节手指以方向与掌面法线对齐参考姿态；站姿和走跑使用源动作的手型，交谈保留作者手势。新增单次伸手交互和拿取手势，含实际手指开合；支持重播。脚趾现为左右各一根整体骨骼，继续使用原走跑轨道，未新增五趾独立关节。无新增 GLB / VRM，参数编辑与原蒙皮权重保持。

验证：`node tests/motion.mjs`（64 组配置、全部 52 条源轨道、30 节手指权重、指节运动及单次末帧保持），`node tests/rig.mjs`，`node tests/pants.mjs`；手部软件渲染近景检查不替代浏览器 WebGL 验收。

## v27 膝盖弯曲与独立鞋色

膝盖按当前骨架的关节位置和腿段长度建立连续的大腿/小腿权重带，改善原裤子周向权重不均产生的套筒状折断。只在膝盖附近对原三角面进行两轮共边中点细分，原静止表面、UV、整体版型和膝盖区域以外的作者蒙皮权重保留；继续计算实际动作表面的法线。无新增服装模型或 GLB，裤宽与身体参数仍有效。

下装颜色与鞋履颜色独立，均支持快捷色、HSL 色板及 HEX 输入、实时预览、存档和 JSON 导入导出。旧存档没有鞋色时继承原下装颜色；改色不重建人物或重置动作。

验证：`tests/pants.mjs` 覆盖男女三种裤宽、同高度裤腿权重连续、膝盖以外原作者权重、UV 接缝、蒙皮后法线一致性；`tests/motion.mjs` 的 64 组动作配置、`tests/rig.mjs` 的八组骨骼配置，以及 `tests/appearance.mjs` / `tests/archive.mjs` 的独立鞋色与旧档迁移检查通过。

## v28 裤腿内侧蒙皮归属修复

膝盖权重调整及局部细分依据原作者大腿/小腿/脚骨骼的蒙皮影响判断裤腿归属，取消按顶点 X 坐标判断左右腿。裤子内侧顶点越过身体中线后仍留在原裤腿，修复被另一腿骨骼拉出的横向三角面及异常明暗；膝盖连续弯曲与独立鞋色保留。

`tests/pants.mjs` 对每个原作者纯单腿顶点检查裤腿归属，覆盖男女、三种裤宽及越过中线的内侧顶点；本检查对 v27 在顶点 6177 明确失败，对修复版通过。六组裤装接缝/法线检查及 64 组动作配置通过。
